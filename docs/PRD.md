# 四级背单词 App —— 产品需求文档（PRD）

| 项 | 内容 |
| --- | --- |
| 项目名 | cet4words |
| 语言 | 中文（简体） |
| 平台形态 | 安卓原生 APK（WebView 混合应用） |
| 前端 | HTML/CSS/JS（离线打包于 `assets/www/`） |
| 外壳 | 零依赖纯 Java 单 Activity（`android.app.Activity`，不引 AndroidX/Kotlin） |
| 目标用户 | 学生（zhang，自用） |
| 数据源 | `kajweb/dict` CET4 词书（约 4000+ 词，精简为 App 内嵌 JSON） |
| 版本 | v1.0 首版 |

---

## 1. 产品目标

**一句话**：一个离线可用、极简无干扰、能科学安排复习的安卓四级背单词工具。

| # | 可验证目标 |
| --- | --- |
| G1 | 用户能在**单次学习流程内**完成「看词→看释义/例句→发音→反馈→自动安排复习」的闭环，卡片页交互无需任何说明即可上手。 |
| G2 | 用户**14 天内**能按艾宾浩斯计划完成 ≥ 500 个四级词的首轮学习，并每天完成打卡。 |
| G3 | 断网状态下，除「有道在线发音」外所有核心功能（背词、收藏、测试、复习、统计、范文）**100% 可用**，数据不丢失。 |

---

## 2. 用户故事

| 功能 | 用户故事 |
| --- | --- |
| 背单词卡片 | As a 备考四级的学生，I want 卡片展示「单词 + 美/英音标 + 释义 + 例句」并支持翻面与点击发音，So that 我能在一次快速浏览中理解并记住这个词。 |
| 生词本 / 收藏 | As a 学生，I want 把陌生词/重点词一键加入生词本并单独复习，So that 我能集中攻克自己的薄弱词。 |
| 单词测试 | As a 学生，I want 通过四选一和拼写两种自测模式检验记忆，So that 我能发现「以为会、其实不会」的词。 |
| 艾宾浩斯复习 + 统计打卡 | As a 学生，I want 系统自动安排复习日期并显示学习统计/打卡，So that 我不必自己规划，也能持续坚持到考试。 |
| 好词好句 / 范文背诵 | As a 学生，I want 查看四级高频好词好句和经典范文，So that 我能同时积累写作素材。 |

## 3. 需求池（P0 / P1 / P2）

### P0 —— 首版必做

| ID | 需求 | 验收标准（Definition of Done） |
| --- | --- | --- |
| P0-1 | 背词卡片 | 卡片正面：单词 + 美/英音标；翻面（或展开）：词性+中文释义、英文解释、例句（含中文译文）。卡片可左右滑动/按钮切换上/下一词；点击词或喇叭图标触发发音。 |
| P0-2 | 有道在线发音 | 联网时用 `dict.youdao.com/dictvoice` 播放，支持美音/英音切换；点击发音 1 秒内出声。 |
| P0-3 | 系统 TTS 回退 | 断网或在线发音失败时，回退安卓 `TextToSpeech` 朗读（语言 en），不弹错误、不卡死。 |
| P0-4 | 生词本/收藏 | 卡片页一个「收藏/取消收藏」按钮；生词本页列出所有收藏词，可点击进入卡片、可移除；数据持久化（localStorage）。 |
| P0-5 | 四选一测试 | 给出单词，4 个中文释义选项；选对/选错即时反馈并计入结果；支持美/英音标与发音。 |
| P0-6 | 拼写测试 | 给出中文释义（+可选音标/发音），用户输入英文单词；提交后判定对错并显示正确拼写；大小写不敏感判定。 |
| P0-7 | 艾宾浩斯复习排期 | 学习反馈三档「认识/模糊/忘记」驱动间隔重排（规则见 §6）；今日复习队列自动生成。 |
| P0-8 | 学习统计 + 打卡 | 记录累计学习词数、今日学习/复习数、连续打卡天数、总打卡天数；首页可见。 |
| P0-9 | 本地数据持久化 | 词库、学习进度、生词本、测试记录、统计、设置均存 localStorage，通过虚拟域名 + `shouldInterceptRequest` 保证可靠持久化，杀进程/重启不丢。 |
| P0-10 | 极简 UI 基线 | 白底黑字、1px 细线分隔、留白、零阴影/零渐变/零霓虹、圆角 4–6px、线描 SVG 图标、禁用 emoji、动效 100–150ms linear 或硬切（铁律见 §7）。 |
| P0-11 | 离线可用 | 词库与页面离线打包，断网可完整使用除「在线发音」外的所有功能。 |
| P0-12 | 打包为原生 APK | 产出可侧载安装的 APK，有桌面图标与正确应用名，Android 8.0+ 可运行。 |

### P1 —— 重要但可后置

| ID | 需求 | 验收标准 |
| --- | --- | --- |

## 4. UI 设计稿说明

> 统一铁律：极简、白底黑字、1px 分隔线、留白、做减法；零阴影/渐变/霓虹；线描 SVG、禁用 emoji；圆角 4–6px；动效 100–150ms linear 或硬切。

### 页面信息架构（6 页）

```
┌─ 底部导航（或顶部分页，固定 5 个入口）────────────────┐
│  今日学习(首页) · 生词本 · 测试 · 范文 · 设置          │
└───────────────────────────────────────────────┘
  今日学习 ──▶ 背单词卡片页（学习/复习同一入口）
  生词本   ──▶ 背单词卡片页（浏览收藏词）
  测试     ──▶ 四选一 / 拼写（选择模式后进入答题流）
  范文     ──▶ 范文详情 / 好词好句列表
  设置     ──▶ 发音偏好、每日目标、深色模式、数据导出
```

### 4.1 首页 / 今日学习

- **顶部**：日期 + 连续打卡天数 + 今日状态（如「已打卡」）。
- **中部主卡片区**：今日学习进度（`今日新词 12/20`）、今日待复习（`待复习 35`）。
- **主按钮**：「开始学习」/「开始复习」两个入口（复习优先置顶）。
- **统计区**：累计学习词数、累计打卡天数、连续天数（3 个小数字块，1px 分隔）。
- **关键交互**：点「开始学习」进入卡片页（新词队列）；点「开始复习」进入卡片页（复习队列）。

### 4.2 背单词卡片页

- **主体**：一张居中卡片。
  - 正面：单词（大号）、美/英音标、发音喇叭图标。
  - 翻面/展开后追加：词性+中文释义、英文解释、例句（英文 + 中文译文）。
- **顶部**：进度（`3 / 20`）+ 收藏按钮（线描星形，实心=已收藏）。
- **底部操作区**：`不认识 · 模糊 · 认识` 三按钮（学习时）；或 `上一张 · 下一张`（浏览生词本时）。
- **发音**：点单词或喇叭即发音（默认音偏好，见设置）。
- **关键交互**：点卡片翻面；点「认识/模糊/忘记」记录反馈并自动切下一词（按 §6 排期）。

### 4.3 生词本

- **列表**：收藏词列表（单词 + 简洁释义 + 收藏日期），1px 分隔线。
- **操作**：点击行进入卡片页浏览；行尾「移除」；顶部「批量管理 / 一键清空」（P1）。
- **空状态**：线描 SVG 图标 + 「暂无收藏词」。

### 4.4 测试

- **入口**：模式选择——「四选一」「拼写」两个卡片按钮。
- **四选一**：题干单词（+音标+发音），下方 4 个中文释义选项；点击即判对错并高亮（1px 边框区分对错），自动进入下一题。
- **拼写**：题干中文释义（+可选发音），输入框 + 提交按钮；判定后显示正确拼写，进入下一题。
- **结束页**：得分（对/错数量）、错词清单（P1 可一键加入生词本）、「再来一组」按钮。
- **空状态**：词库加载前/无词时给出线描空状态提示。

### 4.5 范文背诵

- **列表**：分类——「好词好句」「经典范文」两个 tab 或分区。
- **好词好句**：句/词列表（英文 + 中文），可点击发音。
- **范文**：范文列表 → 详情页（全文，可标记「已背」）；「已背」状态本地记录。

### 4.6 设置

- **分组列表**（1px 分隔）：
  - 发音：默认美音 / 英音（单选）。
  - 学习：每日新词量（20/30/50，默认 20）。
  - 外观：深色模式开关（P1）。
  - 数据：导出进度 / 导入恢复（P1）。
  - 关于：版本号、词库来源说明。

## 5. 数据说明

### 5.1 词库字段（App 内嵌精简 JSON，来自 `kajweb/dict`）

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| `word` | 单词（headWord，唯一键） | 是 |
| `phonetic_us` | 美式音标 | 是 |
| `phonetic_uk` | 英式音标 | 是 |
| `trans` | 词性 + 中文释义数组（如 `[{"pos":"n.","cn":"..."}]`） | 是 |
| `definition` | 英文解释（可空） | 否 |
| `sentences` | 例句数组（`{"en":"...","cn":"..."}`） | 是 |
| `speech_us` | 有道美音发音地址（dictvoice） | 是 |
| `speech_uk` | 有道英音发音地址（dictvoice） | 是 |

> 精简原则：剔除词书中的冗余字段（记忆法、词组、变形、真题等），只保留上表字段，控制内嵌 JSON 体积；`word` 作为所有学习/收藏/测试数据的关联键。

### 5.2 学习记录（localStorage，按 word 索引）

| 字段 | 说明 |
| --- | --- |
| `word` | 单词 |
| `status` | `new` / `learning` / `review` / `mastered` |
| `stage` | 间隔重复阶段（0–6，见 §6） |
| `next_review_at` | 下次复习日期（`YYYY-MM-DD`） |
| `lapses` | 累计忘记次数 |
| `last_review_at` | 上次复习日期 |
| `last_feedback` | 最近反馈（`know` / `fuzzy` / `forgot`） |

### 5.3 生词本

| 字段 | 说明 |
| --- | --- |
| `word` | 单词（关联词库） |
| `added_at` | 收藏时间戳 |

### 5.4 测试结果

| 字段 | 说明 |
| --- | --- |
| `id` | 一次测试唯一 ID |
| `type` | `choice`（四选一）/ `spell`（拼写） |
| `created_at` | 测试时间 |
| `total` / `correct` / `wrong` | 题数 / 对 / 错 |
| `wrong_words` | 错词数组（word + 用户答案 + 正确答案） |

### 5.5 统计 / 打卡

| 字段 | 说明 |
| --- | --- |
| `total_learned` | 累计学习词数（去重） |
| `total_reviewed` | 累计复习次数 |
| `streak_days` | 连续打卡天数 |
| `total_checkin_days` | 累计打卡天数 |
| `last_checkin_date` | 最近打卡日期（判定断签） |
| `daily_new_count` | 今日已学新词数 |

### 5.6 范文 / 好词好句

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一 ID |
| `category` | `quote`（好词好句）/ `essay`（范文） |
| `title` | 标题（范文用） |
| `en` / `cn` | 英文内容 / 中文译文 |
| `memorized` | 是否已背 |

## 6. 间隔重复规则建议（艾宾浩斯）

采用 **SM-2 简化版**：三档反馈 + 固定间隔表，实现简单、无需复杂权重。

### 6.1 间隔表（按阶段 stage）

| stage | 复习间隔 |
| --- | --- |
| 0（新学当天） | 当天再出现 1 次 |
| 1 | 1 天 |
| 2 | 2 天 |
| 3 | 4 天 |
| 4 | 7 天 |
| 5 | 15 天 |
| 6（mastered） | 30 天（满 30 天后归为「已掌握」，移出常规复习，仅留在词库） |

### 6.2 反馈处理

| 反馈 | 处理 |
| --- | --- |
| 认识（know） | `stage = stage + 1`，`next_review_at = 今天 + 间隔(stage)` |
| 模糊（fuzzy） | `stage` 不变，`next_review_at = 今天 + 间隔(stage)`（间隔重算，不推进） |
| 忘记（forgot） | `stage = 0`，`lapses + 1`，`next_review_at = 今天`（当天再出现） |

### 6.3 每日队列生成

- 每日 0 点后首次进入：`待复习 = 所有 next_review_at <= 今天 的词`（按间隔升序，先短后长）。
- 新词：按词书顺序，每日新增 `N` 个（默认 20，设置可调）。
- 学习顺序：复习队列优先于新词队列。

## 8. 附：范围边界（明确不做）

- 不做账号/云同步（纯本地）。
- 不做社交、排行榜、社区。
- 不做 AI 生成内容（用户反感「AI 味」）。
- 首版不引入 AndroidX / Kotlin / 第三方依赖（外壳零依赖）。
